# Suite de Skills ($5,000+ USD Standard) para Antigravity

## Estructura incluida en este paquete
Dentro de este archivo encontraras la carpeta `.agent/skills/` lista para usar con 6 skills especializadas:

1. `master-5k-orchestrator`: Coordina todas las demas skills en orden (Backend -> UI Anti-IA -> 3D PBR -> SVGs -> Pruebas QA).
2. `anti-ai-ui-craft`: Elimina la apariencia generica de IA (cero emojis, cero botones morados brillantes) e implementa diseno estilo Linear/Vercel.
3. `threejs-pbr-architect`: Reemplaza primitivas 3D basicas por ensamblajes complejos con materiales fisicos realistas (PBR) e iluminacion de estudio.
4. `bespoke-svg-craftsman`: Crea ilustraciones SVG tecnicas a medida e iconografia consistente con Lucide/Heroicons.
5. `core-architecture-hardener`: Refactoriza la logica interna, TypeScript estricto, rendimiento, concurrencia y manejo de errores.
6. `autonomous-qa-test-loop`: Ejecuta pruebas en bucle (`tsc`, `lint`, `test`, `npm run build`) corrigiendo errores automaticamente hasta que compile sin fallos para Vercel.

## Instalacion Rapida
Descomprime este archivo en la raiz de tu proyecto para que quede la ruta `.agent/skills/...`
